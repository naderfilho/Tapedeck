Four things worth trying

Where the result comes from

Set the costs to none

The result roughly quadruples. That gap is the whole argument: a backtester that skips fees reports a strategy that does not exist.

Run Bitcoin on both exchanges

Same asset, same year, same rule. On Binance the crossover ends slightly ahead; on Coinbase's entry tier it loses 24%, with fees coming to more than three times the gross profit. A result is a claim about a venue, not about a coin.

Hunt for a better period

Across a 5×5 grid of them, thirteen of nineteen lose money, and none finishes with more winners than losers.

Switch to daily bars

The same rule on the same year, sampled differently, is a different strategy. The daily candles are aggregated from the hourly tape in this tab — nothing extra is downloaded to see them.
